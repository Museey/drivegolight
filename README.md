# DriveGoLight! — ชุดไฟล์สำหรับ www.drivebizbegin.com

## ไฟล์ในชุดนี้

| ไฟล์ | ขนาด | หน้าที่ |
|---|---|---|
| `index.html` | ~63 KB | หน้าเว็บหลัก แนะนำโปรแกรมและมีปุ่มดาวน์โหลด |
| `drivegolight.html` | ~213 KB | ตัวโปรแกรม ไฟล์เดียวจบ คือไฟล์ที่ผู้ใช้ดาวน์โหลดไป |
| `logo.png` | ~25 KB | ตราสัญลักษณ์ ใช้เป็นไอคอนเว็บและภาพตัวอย่างตอนแชร์ลิงก์ |

ไฟล์ที่ **ห้ามอัปโหลด** ขึ้นเว็บ เก็บไว้ในเครื่องของผู้ขายเท่านั้น

| ไฟล์ | หน้าที่ |
|---|---|
| `ออกรหัสลิขสิทธิ์.html` | เครื่องมือสร้างรหัสลิขสิทธิ์ให้ลูกค้าหลังชำระเงิน มีสูตรสร้างรหัสอยู่ภายใน |

## วิธีนำขึ้นเว็บไซต์

1. เข้าระบบจัดการเว็บโฮสติ้งของ `drivebizbegin.com` แล้วเปิดตัวจัดการไฟล์ (File Manager) หรือใช้โปรแกรม FTP
2. เข้าไปที่โฟลเดอร์รากของเว็บ ปกติชื่อ `public_html` `www` หรือ `htdocs`
3. อัปโหลดไฟล์ทั้งสามไฟล์ไว้ในโฟลเดอร์เดียวกัน **ห้ามแยกโฟลเดอร์** เพราะปุ่มดาวน์โหลดอ้างอิงไฟล์ที่อยู่ระดับเดียวกัน
4. เปิด `https://www.drivebizbegin.com` เพื่อตรวจสอบ

โครงสร้างที่ถูกต้อง

```
public_html/
├── index.html
├── drivegolight.html
└── logo.png
```

## ตรวจสอบหลังอัปโหลด

- เปิดหน้าเว็บแล้วเห็นโลโก้และเนื้อหาครบ
- กดปุ่ม **ดาวน์โหลดโปรแกรม** แล้วได้ไฟล์ชื่อ `DriveGoLight.html` ลงเครื่อง
- ดับเบิลคลิกไฟล์ที่ดาวน์โหลด โปรแกรมต้องเปิดใช้งานได้
- กดปุ่ม **ทดลองใช้ทันทีในเบราว์เซอร์** แล้วโปรแกรมเปิดในแท็บใหม่

## ขั้นตอนขายลิขสิทธิ์

1. ลูกค้าดาวน์โหลดโปรแกรมไปทดลองใช้ฟรี 15 วัน นับจากวันที่เปิดโปรแกรมครั้งแรก
2. เมื่อลูกค้าตัดสินใจซื้อ ให้แจ้ง **ชื่ออู่** และ **เลขประจำตัวผู้เสียภาษี 13 หลัก** มาพร้อมหลักฐานการชำระเงิน 3,600 บาท
3. เปิดไฟล์ `ออกรหัสลิขสิทธิ์.html` ในเครื่องของท่าน กรอกข้อมูลลูกค้า เลือกจำนวนปี แล้วกดสร้างรหัส
4. กดปุ่ม **คัดลอกข้อความส่งลูกค้า** แล้วส่งให้ลูกค้าทางไลน์หรืออีเมล
5. ลูกค้านำรหัสไปกรอกที่เมนู **06 ลิขสิทธิ์การใช้งาน** ในโปรแกรม แล้วกดเปิดใช้งาน

เครื่องมือจะเก็บประวัติการออกรหัสไว้ในเครื่องท่าน และส่งออกเป็นไฟล์ CSV ได้
ใช้เตือนตัวเองว่าลูกค้ารายใดใกล้ครบกำหนดต่ออายุ

**เลขประจำตัวผู้เสียภาษีต้องตรงกันทุกหลัก** ระหว่างที่ท่านใช้ออกรหัส กับที่ลูกค้ากรอกในเมนูตั้งค่าร้าน
มิฉะนั้นรหัสจะใช้ไม่ได้ หากลูกค้าแจ้งปัญหา ให้ใช้ช่องตรวจสอบรหัสในเครื่องมือเดียวกันนี้ตรวจดูก่อน

## ขีดความสามารถของโปรแกรม

| รายการ | ขีดจำกัด |
|---|---|
| ทะเบียนอะไหล่ | สูงสุด 3,000 รายการต่อหนึ่งชุดข้อมูล |
| ทะเบียนลูกค้า | ไม่จำกัด |
| ใบเสนอราคาและใบเสร็จ | ไม่จำกัด |
| จำนวนผู้ใช้ในอู่เดียวกัน | ไม่จำกัด |

หน้าสต๊อกแสดงจำนวนที่ใช้ไปเทียบกับขีดจำกัดตลอดเวลา เมื่อถึง 2,700 รายการจะขึ้นแถบเตือนสีเหลือง
และเมื่อครบ 3,000 รายการจะเพิ่มรายการใหม่ไม่ได้จนกว่าจะลบรายการเดิมออก
ทั้งนี้การแก้ไขและลบรายการเดิมยังทำได้ตามปกติแม้ทะเบียนจะเต็มแล้ว

## ข้อจำกัดของระบบลิขสิทธิ์ที่ต้องทราบ

โปรแกรมนี้ทำงานในเครื่องลูกค้าทั้งหมด ไม่มีเซิร์ฟเวอร์ตรวจสอบ ระบบทดลองใช้จึงเป็นการเตือนตามความสุจริต
ไม่ใช่การป้องกันเชิงเทคนิคที่แน่นหนา ผู้ใช้ที่มีความรู้ทางเทคนิคสามารถหลบเลี่ยงได้ เช่น

- ล้างข้อมูลเบราว์เซอร์ หรือดาวน์โหลดไฟล์ใหม่ แล้วเริ่มนับ 15 วันใหม่
- ปรับวันที่ของเครื่องย้อนหลัง
- แก้ไขโค้ดในไฟล์ HTML โดยตรง

หากต้องการป้องกันจริงจัง ต้องมีเซิร์ฟเวอร์ตรวจสอบสิทธิ์ทุกครั้งที่เปิดโปรแกรม
ซึ่งจะทำให้ใช้งานออฟไลน์ไม่ได้และมีค่าดูแลระบบเพิ่ม
สำหรับลูกค้ากลุ่มอู่ซ่อมรถทั่วไป ระบบปัจจุบันเพียงพอต่อการทำธุรกิจตามปกติ

## การอัปเดตโปรแกรมรุ่นใหม่

1. นำไฟล์ `drivegolight.html` รุ่นใหม่ไปวางทับไฟล์เดิม
2. แก้เลขรุ่น ขนาดไฟล์ และวันที่ปรับปรุงใน `index.html` (ค้นคำว่า `รุ่น 1.2`)
3. แจ้งผู้ใช้ให้สำรองข้อมูลเป็นไฟล์ JSON ก่อนเปลี่ยนไฟล์โปรแกรม แล้วกู้คืนหลังเปลี่ยน

## ข้อควรทราบ

- ผู้ใช้แต่ละคนเก็บข้อมูลไว้ในเครื่องตัวเอง เว็บไซต์นี้ทำหน้าที่แจกไฟล์อย่างเดียว ไม่มีฐานข้อมูลฝั่งเซิร์ฟเวอร์
- อย่าลืมแก้ช่องทางติดต่อสั่งซื้อในไฟล์ `index.html` (ค้นคำว่า `สั่งซื้อหรือสอบถามเพิ่มเติม`) ให้เป็นเบอร์โทร ไลน์ไอดี หรืออีเมลของท่าน
- ควรเปิดใช้ HTTPS เพื่อไม่ให้เบราว์เซอร์เตือนตอนดาวน์โหลด
- หากเบราว์เซอร์เปิดไฟล์แทนการดาวน์โหลด ให้ผู้ใช้คลิกขวาที่ปุ่มแล้วเลือก บันทึกลิงก์เป็น
- หากแก้ไฟล์แล้วหน้าเว็บยังแสดงของเดิม ให้กด Ctrl+F5 เพื่อล้างแคชของเบราว์เซอร์
